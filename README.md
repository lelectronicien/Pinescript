# Pine Script Research Archive

A collection of TradingView Pine Script indicators, strategies, and quantitative trading ideas.

## Layout

- `indicators/`: original research indicators and chart tools.
- `strategies/`: backtestable trading strategies (to be added).

## Scripts

### MMM Market Structure & Order Flow Suite v3.0

Source: `indicators/MMM_Market_Structure_Order_Flow_Suite_v3.pine`

A Pine Script v6 indicator shared for archival. Features market-structure swing levels, auction-state candles, momentum accelerators, liquidity gaps, footprint/synthetic delta, higher-timeframe levels, and risk projection grids.

**Status:** Original source, not independently compiled or verified in TradingView. This is an **indicator**, not an executable/backtestable `strategy()`. Real footprint data availability depends on TradingView access; the script includes a synthetic-delta fallback. Attribution in the script header is retained.

## Disclaimer

Research and educational purposes only. Signals and visualizations are not evidence of profitability. Test scripts on TradingView and with historical/realtime data before use.
